# MyDiary

A polished front-end prototype for a private digital diary.

## Included
- Dashboard and daily writing
- Rich-feeling journal workflow
- Calendar, search and tags
- Mood tracking and streak/stat cards
- My Life Search
- AI reflection placeholder
- Future-self letters
- Memory Vault
- Goals & dreams
- Random memory / On this day concepts
- Voice typing where browser support exists
- Local browser persistence
- PIN lock
- JSON export
- Responsive mobile layout
- Theme controls

## Run
Open `index.html` in a modern browser. No build step is required.

## Production note
For a real private diary product, add authenticated accounts, server-side encryption/key management, secure backups, access controls, rate limiting, audited dependencies and a carefully designed privacy policy. The included PIN is only a local prototype lock.
